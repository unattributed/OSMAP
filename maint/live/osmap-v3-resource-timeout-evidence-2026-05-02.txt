Scope
-----

This evidence covers the first V3 resource and timeout proof slice:

- helper-backed mailbox list behavior when the helper does not respond
- helper-backed message search behavior when the helper does not respond
- helper-backed message view behavior when the helper does not respond
- route-level deadline propagation into helper-backed search/view policy
- route-class search budget exhaustion and cheap-route availability
- route-class mailbox budget release after a message-view backend failure
- route-class mailbox budget exhaustion for compose reply/forward source
  loading
- route-class mailbox budget exhaustion for message move
- route-class mailbox budget exhaustion for attachment download
- route-class search budget exhaustion for all-mailbox search fanout
- route-class send budget exhaustion after session and CSRF validation
- route-class auth budget exhaustion without session or credential-stage leakage
- aggregate all-mailbox search fanout deadline detection and redacted deadline
  audit evidence
- per-mailbox all-mailbox-search backend construction with the remaining
  aggregate route deadline
- route-level command timeout propagation for direct `doveadm` message
  search/view/move, sendmail, and external auth
- route-level helper timeout propagation for helper-backed message
  search/view/move and attachment download
- bounded public failure rendering for oversized message-view output
- HTTP read timeout behavior
- external command timeout behavior

The proof is intentionally safe and non-destructive. It uses unit/integration
tests with synthetic fixtures and local Unix-domain sockets. It does not access
real mailboxes or live private message content.

Release interpretation
----------------------

The release gate treats this file as the current resource-timeout evidence path
through `OSMAP_RELEASE_RESOURCE_TIMEOUT_EVIDENCE`. A release-mode run must fail
if the configured resource-timeout evidence is missing or empty.

Remaining V3 work
-----------------

This closes the current evidence path for helper-backed mailbox/search/message
view timeout behavior, route-class budget exhaustion, command/helper deadline
propagation, and bounded failure mapping for the expensive browser route
classes currently in scope. Unit tests prove the helper policy does not exceed
the route cap, keeps tighter helper defaults when they are already stricter,
records search/mailbox/send/auth budget exhaustion safely, caps direct
`doveadm`, sendmail, and auth command timeouts used by those routes, and emits
redacted all-mailbox fanout deadline evidence.

Future V3 resource-control work should add evidence only when a new expensive
route class is introduced or a live-host validation identifies a specific
unbounded failure mode.
