Scope
-----

This evidence covers the first V3 resource and timeout proof slice:

- helper-backed mailbox list behavior when the helper does not respond
- helper-backed message search behavior when the helper does not respond
- helper-backed message view behavior when the helper does not respond
- route-level deadline propagation into helper-backed search/view policy
- route-class search budget exhaustion and cheap-route availability
- route-class mailbox budget release after a message-view backend failure
- bounded public failure rendering for oversized message-view output
- HTTP read timeout behavior
- external command timeout behavior

The proof is intentionally safe and non-destructive. It uses unit/integration
tests with synthetic fixtures and local Unix-domain sockets. It does not access
real mailboxes or live private message content.

Release interpretation
----------------------

The release gate treats this file as the current resource-timeout evidence path
through `OSMAP_RELEASE_RESOURCE_TIMEOUT_EVIDENCE`. A release-mode run must fail
if the configured resource-timeout evidence is missing or empty.

Remaining V3 work
-----------------

This closes the first evidence path for helper-backed mailbox/search/message
view timeout behavior and bounded failure mapping. The follow-up implementation
now propagates `OSMAP_EXPENSIVE_REQUEST_TIMEOUT_SECONDS` into helper-backed
message search and message view, with unit tests proving the helper policy does
not exceed the route cap and keeps tighter helper defaults when they are already
stricter. Send worker budgets, auth worker budgets, and deadline propagation for
the remaining expensive route classes remain separate V3 resource-control work
items.
